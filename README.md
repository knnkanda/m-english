# M English（マサソンイングリッシュ）

🎮 **プレイはこちら: [m-english-psi.vercel.app](https://m-english-psi.vercel.app)**

ビジネス英語の **S（主語）→ V（動詞）→ O・C（目的語・補語）→ M（修飾語）** という語順を、テトリス風に落ちてくる単語ブロックを正しいレーンでキャッチしながら体に覚えさせるブラウザゲームです。

外部ライブラリなしの素の HTML / CSS / JavaScript のみで動作し、効果音も Web Audio API でその場で合成しています。

## 遊び方

1. 画面下に **S / V / O・C / M** の4レーンが並んでいます。
2. 上から英単語・フレーズのカタマリが落ちてきます。
3. ← → キー（またはボタン・タップ）でレーンを選び、正しい文法的役割のレーンでキャッチします。
4. 1文ぶんのチャンクをすべて正しく配置すると、英文・和訳・SVOC タグの解説が表示されます。
5. レベル1（S+V）→ レベル2（S+V+O・C）→ レベル3（+ 修飾語 M）と、文の構造が段階的に複雑になっていきます。

## インスピレーション

このプロジェクトは、ソフトバンクグループ代表の**孫正義氏の英語スピーチ**からインスピレーションを受けています。

発音がネイティブのように完璧でなくても、

- 主語・動詞を短く言い切る
- 目的語・補語に結論（伝えたいキーワード）を置く
- 場所・時・理由などの具体的な情報は「後付け」で足していく

という **SVOC の語順を崩さない話し方**は、非ネイティブの聞き手にとっても非常に聞き取りやすく、伝わる英語の好例です。

本ゲームに収録されている例文は、孫氏のスピーチの逐語的な書き起こしではなく、その特徴的な話し方やテーマ（AI、ビジョン、投資哲学、ロボティクスなど）から着想を得て独自に作成したオリジナルの文章です。

## 収録例文（250問）

[`sentences.js`](./sentences.js) に、ビジネス英語として実用的な250の例文を収録しています。

- **レベル1（S+V）**: 10問（骨組みの導入。すぐにレベル2へ進みます）
- **レベル2（S+V+O・C）**: 150問
- **レベル3（S+V+O・C+M）**: 90問

AI・テクノロジー / リーダーシップ・ビジョン / 金融・投資 / マーケティング・ブランディング / 経済・市場 / プレゼンテーション・コミュニケーション / 経営戦略・組織 / 交渉・M&A / グローバル展開・サプライチェーン / スタートアップ・成長　の10テーマに分けており、SVOCの型だけでなく経済・金融・マーケティング分野のビジネス語彙も身につくように構成しています。

例文データはゲーム本体（`index.html`）と分離しているので、今後さらに問題数を増やす場合も `sentences.js` を編集するだけで済みます。

## 技術スタック

- Vanilla HTML / CSS / JavaScript（フレームワーク・外部ライブラリ依存なし）
- 例文データは `sentences.js` に分離（`index.html` から `<script src="sentences.js">` で読み込み）
- 効果音は Web Audio API によるリアルタイム合成（音声ファイル不使用）
- Google Fonts（Press Start 2P / Noto Sans JP / JetBrains Mono）

## ローカルで試す

```bash
# このリポジトリを clone 後
npx serve .
# もしくは
python3 -m http.server 8080
```

`index.html` を開くだけでも動作します。
